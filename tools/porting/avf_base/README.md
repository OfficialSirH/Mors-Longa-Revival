# AVF base files (third-party, credited)

Unmodified copies (line endings converted to LF) of four files from **Armed Vehicles Framework (AVF)** by
**elboydo**, Steam Workshop item 2400346027, version `V-3.0.2` (AVF_VERSION.lua), copied 2026-11-12:

* `kinetic_effects.lua` – shell flight, impact, penetration outcomes, spalling, shrapnel, HE payload
* `main.lua` – AVF's main script (only some functions are used: penetration check, material tables, impact
  effects, the Mors Longa NPC damage hook, `globalConfig`)
* `ammo.lua` – shell types (`munitions`), config override keys, penetration / ricochet modifiers
* `explosionController.lua` – explosion visuals

AVF's main.lua says: "Copyright - Of course no copyright but please give credit if this code is re-used in part
or whole by yourself or others." The port (Mors Longa Revival, Phase 4 step 3, cannons) is built from these files
by a converter, so the changes stay reviewable; credit AVF / elboydo in the mod's credits when publishing.

Do not edit these files: they are the converter's base.
